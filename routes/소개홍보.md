# 소개·홍보 모션 활용 루트

조사·확인일: 2026년 9월 30일. 대상: 제품·서비스 소개, 홍보 영상, 출시 티저, 훅, 제품 리빌, 로고 스팅, CTA. 결과물 형식: 효과 카탈로그를 실제 비트에 배치하는 판단 문서.

**기본 루트: 목표 행동 1개 → 매체와 시청 환경 → 고객 문제와 가치 약속 → 보여 줄 증거 → 비트와 읽기 시간 → 효과 조합 → 접근성 대안 → 검수.** 효과부터 고르지 않아.

근거 표기: **공식**은 매체 가이드·표준의 직접 내용, **설계 제안**은 그 내용을 소개·홍보 용도에 적용한 제작 시작값. 아래 초·이동량·효과 횟수는 별도 표시가 없으면 설계 제안이야. 특정 효과가 클릭률·구매율을 높인다는 보장으로 읽지 마. 플랫폼 연구는 해당 광고 환경의 결과이며, 서로 다른 매체와 브랜드에 그대로 일반화하지 않아.

로컬 사전은 실제로 있는 「00 한눈에」, 「2 전환·컷·카메라」, 「3 타이포와 데이터 애니메이션」을 참고했어. 목차에만 있는 「1 애니메이션 원칙과 모션 기본기」와 「4 설명 영상 연출과 학습 원리」는 본문을 확인하지 못했어. 기존 사전의 3~5분 설명 영상용 시간값을 짧은 광고에 그대로 옮기지 않고, 읽기 홀드와 조합 원칙을 가져왔어. [L1][L2][L3]

## 1. 목표와 제약

### 목표에 따라 성공 신호부터 정해

| 목적 | 시청자가 남겨야 할 것 | 확인할 신호 | 모션의 역할 |
| :--- | :--- | :--- | :--- |
| 인지도 | 어떤 브랜드가 무엇을 제공하는지 | 브랜드·제품 회상, 초반 이탈, 도달 | 제품·브랜드 단서를 일찍 보여 주고 중요한 순간에 반복 |
| 고려 | 나에게 어떤 이익이 있는지, 어떻게 작동하는지 | 가치 약속 이해, 시연 구간 유지, 상세 페이지 유입 | 문제와 결과를 연결하고 작동 증거를 읽게 함 |
| 전환 | 왜 지금 어떤 행동을 해야 하는지 | CTA 이해, 클릭 뒤 가입·문의·구매 | 증거 다음에 한 가지 행동을 또렷하게 제시 |
| 출시 티저 | 무엇을 기대하고 언제 어디서 확인하는지 | 제품 범주·출시일 회상, 알림 신청 | 일부를 숨겨 기대를 만들되 식별 정보와 다음 행동은 확정 |

공식 근거: Google ABCD는 주의, 브랜딩, 연결, 행동 방향을 제시하고, 목표에 따라 제품 작동·구체적 가치·CTA 맥락을 다르게 강조해. 이 표의 검수 신호와 측정 조합은 설계 제안이야. [S1]

### 매체·길이·환경을 먼저 잠가

| 환경 | 공식 근거와 제약 | 이 루트의 제작 선택 |
| :--- | :--- | :--- |
| TikTok 같은 세로 피드 | TikTok은 9:16, 720p 이상, 플랫폼 UI를 피한 배치를 권장. 훅·본론·마무리 구조 제시. [S2] | 기본 작업 크기 1080×1920, 15초 또는 30초부터 설계. 이 길이는 플랫폼 상한이 아니라 템플릿 길이. 첫 프레임부터 의미 있는 제품·문제·결과 배치 |
| YouTube 건너뛸 수 있는 인스트림 | 5초 뒤 건너뛰기 가능. [S4] | 5초 전에 제품 식별과 가치 약속 전달. 긴 독립 로고 오프닝 대신 제품 장면 안에 브랜드 삽입 |
| YouTube 범퍼 | 확인 시점 공식 비교표는 5~6초 규격 제시. [S4] | 6초 템플릿 사용. 약속 하나와 브랜드 하나, 짧은 행동 하나로 압축. 15초 영상을 배속하지 않아 |
| 제품 상세 페이지·랜딩 영상 | Google은 기기 가독성과 경쟁 요소 억제를 강조. 웹 자동 모션에는 별도 제어 조건 존재. [S1][S8] | 30초 또는 45초 시연형. 재생·일시정지 제공. 페이지 본문과 경쟁하는 자동 반복 영상은 중단 제어 검토 |
| 행사·전시·디지털 사이니지 | 현장별 거리·소음·화면 크기 확인 필요. 이 문서에서 보편 길이 규격을 확정하지 않아 | 무음 완결형과 멀리서 읽히는 짧은 문구. 시작점이 임의일 때도 제품명·혜택 식별 가능. QR은 정지 상태에서 실제 거리로 스캔 시험 |
| 무음 시청 | TikTok의 소리 활용 권장과 별개로, 소리를 못 듣는 시청자에게 의미를 제공해야 함. 녹화 음성의 자막은 WCAG 1.2.2 수준 A 근거. [S2][S5] | 핵심 약속·조건·CTA를 화면에도 표시. 소리 켜짐 버전에는 발화·음악·효과음을 동작과 정렬 |

안전 영역은 플랫폼·지면·캡션·광고 버튼에 따라 달라져. 모든 세로 영상에 같은 하단 여백 비율을 강제하지 않아. 실제 게재 UI를 겹쳐 제품명·자막·가격·CTA가 가려지는지 확인해. TikTok 자료의 여백 그림을 Reels·Shorts의 고정 규격으로 전용하지 않아. [S2][S3]

### 접근성은 화면과 배포 환경을 함께 판단해

| 항목 | 근거와 적용 범위 | 설계·완성 조건 |
| :--- | :--- | :--- |
| 자막 | 녹화 동기화 미디어의 음성 자막, WCAG 1.2.2 수준 A. [S5] | 대사와 의미 있는 소리 표시. 키네틱 제목이 자막 전체를 대신하지 않게 함. 발화 시점과 자막 동기 확인 |
| 텍스트 대비 | 일반 텍스트 4.5:1, 큰 텍스트 3:1, WCAG 1.4.3 수준 AA. [S6] | 자막·가격·날짜·CTA 대비 점검. 밝은 제품 장면에서는 고정 배경판 사용. 로고의 예외를 본문에 확대 적용하지 않아 |
| 섬광 | WCAG 2.3.1 수준 A는 1초 안에 3회를 넘는 섬광을 제한하거나 면적·밝기·적색 임계값 충족 요구. [S7] | 이 루트는 전면 플래시·적색 스트로브를 배제. 정확히 3회면 언제나 안전하다는 제작 규칙을 만들지 않아 |
| 자동 반복 모션 | 자동 시작·5초 초과·다른 콘텐츠와 병렬 표시 조건이면 일시정지·정지·숨김 수단 필요, 필수 모션 예외 존재. WCAG 2.2.2 수준 A. [S8] | 웹 히어로 영상에 정지 제어 제공. 모든 5초 초과 영상 자체가 위반이라는 식으로 해석하지 않아 |
| 사용자 입력으로 생기는 큰 이동 | 상호작용에 의한 비필수 모션을 끌 수 있어야 한다는 WCAG 2.3.3 수준 AAA 근거. [S9] | 웹 애니메이션은 모션 감소 설정 반영. 출력 MP4 내부 동작은 CSS 설정으로 바뀌지 않으므로 큰 줌·팬을 덜어낸 별도 버전 또는 정적 대안 준비 |
| 시각 정보 설명 | 중요한 시각 정보가 기존 음성에 포함되면 추가 화면 해설이 필요 없을 수 있음. WCAG 1.2.5 수준 AA. [S10] | 제품 사용 결과·가격 조건·출시일·행동을 내레이션에도 담음. 시각으로만 이해되는 시연은 화면 해설 검토. 텍스트 대안만으로 이 AA 항목을 충족했다고 판정하지 않아 |

WCAG 표는 웹 배포의 접근성 판단 근거야. 이 문서의 체크만으로 전체 페이지·플레이어의 WCAG 적합성을 인증하지 않아.

## 2. 설계 로직

### 판단 순서

| 순서 | 먼저 답할 질문 | 확정할 결과 | 다음 판단 |
| :--- | :--- | :--- | :--- |
| 1 | 누구에게 무엇을 하게 할까 | 대상 1개, 목적 1개, CTA 동사 1개 | 인지도면 제품 식별, 전환이면 행동 이유 우선 |
| 2 | 어디에서 몇 초 동안 어떤 상태로 볼까 | 매체, 지면, 화면비, 길이, 음성, 게재 UI | 6초는 단일 메시지형, 15초는 압축형, 30~45초는 시연형 |
| 3 | 고객의 문제와 제품 약속이 한 문장으로 연결될까 | 문제 1개, 가치 약속 1개 | 설명이 길면 기능 수를 줄임. 제품이 낯설면 범주부터 표시 |
| 4 | 약속을 무엇으로 확인시킬까 | 실제 사용 장면·결과·검증된 수치 중 핵심 증거 | 증거가 없으면 수치 효과 대신 사용 맥락·제품 형태를 보여 줌 |
| 5 | 첫 프레임과 리빌 순간에 무엇이 보여야 할까 | 훅 유형, 제품 식별 시점, 브랜드 단서 | 기능 이해가 중요하면 결과 훅, 출시 기대면 부분 리빌 |
| 6 | 어느 정보를 읽고 어느 동작을 봐야 할까 | 비트별 시작·종료, 진입·정지·전환 시간 | 전체 길이가 넘치면 효과 속도보다 메시지 수부터 줄임 |
| 7 | 효과를 빼면 관계·시선·브랜드 인지가 약해질까 | 비트당 주효과 1개와 필요한 보조 강조 | 역할이 없는 장식은 제거. CTA는 진입 후 정지 |
| 8 | 무음·작은 화면·모션 감소에서도 뜻이 남을까 | 자막·정적 상태·저모션 대안 | 이동을 제거해도 제품명·결과·CTA 유지 |
| 9 | 무엇을 바꾸어 검증할까 | 비교할 변수와 판정 기준 | 같은 본론·CTA에서 훅만 바꾸거나, 같은 훅에서 리빌만 바꿈 |

1~5단계의 방향은 매체 가이드에서 가져오고, 6~9단계의 제작 절차와 효과 예산은 이 루트의 설계 제안이야. [S1][S2][S3]

### 상황 → 효과 조합 → 이유

| 상황·트리거 | 쓸 효과·조합과 순서 | 이유·적용 근거 | 교체·중단 조건 |
| :--- | :--- | :--- | :--- |
| 제품이 낯설고 사용 이익이 직관적 | 완성 결과 인서트 → 짧은 가치 문구 마스크 리빌 → 제품 전체 숏 | 결과를 먼저 보여 주고 제품을 연결하는 훅. 메시지 집중을 구체화한 제안. [S1][L2][L3] | 결과만 보면 제품 범주를 모르면 제품명·범주 라벨을 첫 장면에 추가 |
| 문제와 해결 차이가 눈에 보임 | 문제 숏 → 같은 기준점 매치컷 → 개선 결과 정지 → 차이 하이라이트 | 컷은 빠르게, 비교는 읽게 만듦. 대응 위치를 유지하면 연결 의도가 명확해짐. [L2] | 조명·축척·조건이 달라 효과가 과장되면 동일 조건 비교로 재구성 |
| 출시 전 호기심이 목적 | 부분 실루엣·클로즈업 → 한 번의 마스크 리빌 → 전체 제품 → 날짜와 알림 CTA | 기대와 식별을 분리. 훅의 긴장·놀라움 사용은 공식 방향, 구체 조합은 제안. [S2][S3] | 끝까지 제품 범주·브랜드를 모르면 숨김 강도를 줄임 |
| 기능 사용이 구매 이유 | 전체 UI → 커서 이동 → 클릭 리플 → 결과 변화 → 확대 콜아웃 → 정지 | 입력과 결과를 연결해 작동 증거를 읽힘. [L3] | 한 비트에 타이핑·카메라·카운터가 동시에 움직이면 순서로 분리 |
| 작은 물성·질감·부품이 차별점 | 제품 전체 숏 → 세부 인서트 또는 느린 푸시인 → 전체 맥락 복귀 | 세부를 읽되 제품 정체성 유지. [L2] | 해상도가 부족하거나 줌으로 형태를 잃으면 고해상도 인서트로 교체 |
| 동일 대상의 상태 변화가 핵심 | 공유 요소 모프 → 결과 라벨 → 정지 | 같은 대상이 바뀐다는 연속성 표현. [L2][L3] | 다른 제품·다른 조건을 하나의 변형처럼 보이게 하면 컷과 명시 라벨 사용 |
| 검증된 성과 수치를 보여 줌 | 고정 단위·분모·조건 → 카운트업 또는 막대 성장 중 하나 → 최종 값과 출처 정지 | 수치의 최종 상태를 읽게 하는 주목 장치. [L3] | 실측 근거가 없으면 사용하지 않아. 중간 값은 실제 시계열처럼 표시하지 않아 |
| 신뢰·정밀함이 중요 | 하드 컷 → 안정된 시연 → 짧은 주석 → 낮은 진폭 강조 | Carbon의 효율적 모션 방향을 시연에 적용. 고무 같은 움직임을 줄임. [S11] | 클릭 대상·작업 결과보다 장식이 먼저 보이면 장식 제거 |
| 친근하고 놀이감 있는 소비재 | 짧은 스케일 팝 1회 → 제품 리빌 → 정지 | 브랜드 성격을 한 순간에 표현하는 설계 제안. Carbon 규칙에서 나온 바운스 권장이 아님 | 가격·수치·CTA 글자에는 오버슈트 적용하지 않아 |
| 로고 스팅이 필요 | 이미 보이는 브랜드 단서 → 형태 또는 선 드로우 → 완성 로고 정지 | 브랜딩을 초반에도 유지하고 끝에 인지 상태를 확정. [S1][L2][L3] | 짧은 광고에서 로고만으로 2초 이상 시작하면 제품 장면에 통합 |
| 상담·신청·구매로 끝내야 함 | 증거 정지 → CTA 패널 짧은 진입 → 행동·도착 위치 정지 | 구체 맥락 뒤 행동 요청이라는 공식 방향 적용. [S1] | 두 행동이 경쟁하면 하나만 남김. 버튼처럼 보이는 영상 그래픽의 실제 클릭 위치를 설명 |
| 음악 박자가 빠름 | 의미가 바뀌는 박자에 컷 → 결과 읽기 홀드는 음악 위로 유지 | 음향을 구조에 활용하되 정보보다 박자가 우선하지 않게 함. [S2][S3] | 음악에 맞추려고 문구가 읽히기 전에 사라지면 컷을 늦춤 |
| 모션 민감 사용자·웹 저모션 버전 | 큰 이동·회전·시차 제거 → 즉시 컷 또는 짧은 페이드 → 최종 상태 | 모션 감소의 정보 보존 원칙. [S9][L3] | 모션을 끄면서 리빌 대상·최종 수치가 함께 사라지면 실패 |

### 조합 예산

1. 한 비트의 기본은 **주효과 1개 + 보조 강조 1개 이하 + 읽기 홀드**. 예: 제품 마스크 리빌 + 제품명 고정, 또는 UI 줌 + 주석 등장. 이 개수는 제작 통제용 제안이야.

2. 카메라가 이동하는 동안 긴 카피·숫자 갱신을 추가하지 않아. 도착 → 주석 등장 → 읽기 순서로 분리해. 핵심어 1~2개 외에는 자막을 안정된 위치에 둬. 경쟁 요소 억제라는 공식 원칙을 적용한 조합이야. [S1][L3]

3. 강한 브랜드 동작은 훅이나 리빌 중 한 곳을 주무대로 정해. 휩팬·글리치·큰 팝을 모든 컷에 반복하지 않아. CTA 구간은 진입이 끝나면 제품명·행동·조건을 정지시켜.

4. 작은 한글 본문은 글자별 분해보다 단어·행 단위로 공개해. 글자별 동작이 필요하면 한글 자모가 분리되지 않게 완성 글자 단위를 사용해. [L3]

## 3. 구조 템플릿

아래 구간은 최종 타임라인 기준이야. 진입·전환·정지 시간을 해당 구간 안에 포함해. 겹치는 전환은 인접 비트의 경계 안에서 처리하며 표 길이 뒤에 추가하지 않아. 30fps 작업 시작값이면 0.1초는 3프레임. 다른 프레임률에서는 실제 프레임 경계로 반올림해. 모든 길이와 비트 배치는 설계 제안이야.

### A. 6초 단일 약속 범퍼

용도: 이미지를 각인하거나 긴 광고의 핵심 약속을 한 번 더 알릴 때. 공식 범퍼 규격과 초반 브랜드 방향 참고. [S4][S1]

| :--- | :--- | :--- | :--- |
| 0.0~1.0초 | 훅: 제품과 핵심 결과 함께 표시 | 첫 프레임 의미 완성, 필요하면 0.2초 스케일 진입 | 제품명 또는 식별 가능한 제품·브랜드 단서부터 보임 |
| 1.0~3.6초 | 약속·증거: 하나의 이익을 사용 장면으로 확인 | 0.4초 마스크 리빌 또는 매치컷, 이후 결과 정지 | 짧은 한 문장만 추가. 여러 기능 몽타주 금지 |

조합: 결과 인서트 → 제품 리빌 → 짧은 스팅 → CTA 정지. 긴 URL·복수 조건·QR 스캔을 요구해야 하면 15초 이상 템플릿으로 이동해.

### B. 15초 문제 해결 소개·홍보

용도: 세로 피드에서 문제 하나, 이익 하나, 시연 하나, 행동 하나를 전달할 때. 훅·본론·마무리 구조를 적용한 제안. [S2]

용도: 낯선 서비스, 화면 사용이 구매 판단에 필요한 제품, 상세 페이지 영상. Google의 고려·행동 목적 방향을 적용한 제안. [S1]

## 4. 권장 효과와 파라미터

### 공통 단위·이징·원칙

시간은 초, W/H는 각각 최종 화면 폭/높이, scale은 최종 크기 대비 배율. 화면비 변경 때 텍스트와 UI를 다시 배치해. 작은 화면을 위해 모든 요소를 단순 비례 축소하지 않아.

| 키 | 명시할 곡선 | 이 루트의 쓰임 |
| :--- | :--- | :--- |
| LIN | `cubic-bezier(0, 0, 1, 1)` | 페이드·등속 선 드로우·일정한 진행 |
| ENT | Carbon productive entrance, `cubic-bezier(0, 0, 0.38, 0.9)` | 제목·CTA·주석 진입 |
| STD | Carbon productive standard, `cubic-bezier(0.2, 0, 0.38, 0.9)` | UI 위치·크기·공유 요소 변화 |
| EXP | Carbon expressive standard, `cubic-bezier(0.4, 0.14, 0.3, 1)` | 선택한 제품 리빌 순간 |
| SOFT | `cubic-bezier(0.42, 0, 0.58, 1)` | 느린 푸시인·짧은 카메라 재배치용 제안 |

Carbon은 UI 모션 체계야. ENT·STD·EXP의 곡선 값과 효율적·표현적 모션 구분을 참고했지만, 아래 영상용 시간 범위의 실험 근거는 아니야. 큰 거리·크기 변화에는 더 긴 시간을 쓰고, 표현적 모션은 중요한 순간에 제한하라는 방향을 적용해. Carbon은 바운스·늘어남을 피하라고 하므로 소비재 팝은 별도의 브랜드 연출 제안으로 구분해. [S11]

GSAP 같은 도구에서는 cubic-bezier와 비슷한 이름의 기본 ease가 수학적으로 같다고 가정하지 않아. 정확한 곡선이 필요하면 지원 변환 기능을 사용해. 이 문서는 구현 라이브러리를 강제하지 않아. [L2][L3]

| 원칙 | 소개·홍보에서의 적용 |
| :--- | :--- |
| 시선 우선순위 | 제품·혜택·증거·CTA 중 현재 비트의 중심 하나 결정. 나머지는 정지 또는 낮은 대비 |
| 예고 | 리빌 전 짧은 부분 노출·방향 신호. 중요한 제품 식별을 지나치게 늦추지 않아 |
| 감속·정착 | 진입 후 최종 상태를 멈춰 읽게 함. 효과 종료가 정보 종료가 아님 |
| 연속성 | 같은 대상은 같은 기준점·방향을 유지. 다른 대상·조건은 라벨과 컷으로 구분 |
| 후속 동작 | 보조선·장식은 주동작 뒤 짧게 정착. 가격·본문·CTA를 계속 흔들지 않아 |

이 표는 연출 원칙을 이 용도에 적용한 설계 제안이야. 광고 성과가 검증된 개별 기법 목록은 아니야.

## 5. 에이전트 프롬프트 예시 3개

### 예시 1. 15초 SaaS 소개·홍보

> `routes/소개홍보.md`의 판단 순서와 B 템플릿으로 일정 관리 서비스 ‘팀캘’의 15초 9:16 소개 영상을 설계해. 대상은 일정 조율이 잦은 소규모 팀, 약속은 ‘팀 일정을 한 화면에서 확인’, CTA는 ‘무료로 시작하기’, 실제 도착 위치는 게시물에 연결된 가입 페이지야. 제공된 실제 녹화의 일정 선택·공유 화면만 증거로 써. 비용·시간 절감 수치는 만들지 마. 첫 프레임에 문제와 제품 단서를 넣고 4.5~9.5초에는 핵심 조작 하나만 보여 줘. 대비 컷 → 제품 리빌 → 클릭·결과 → 확대 콜아웃 → CTA 정지 조합을 써. 장면별 시작·종료 초, 카피, 주효과, 이징, 이동량, 완성 상태 홀드, 자막, 음향, 저모션 대안을 표로 제시한 뒤 제작해. 무음에서도 이해되게 하고 실제 게재 UI에서 안전 영역을 확인해. 대기를 줄이면 생략을 표시하고 12~15초 CTA는 진입 후 정지해.

### 예시 2. 12초 제품 출시 티저

> 이 루트의 D 템플릿으로 무선 조명 ‘루미’의 12초 출시 티저를 설계하고 제작해. 대상은 작은 방을 꾸미는 사용자, 핵심 차별점은 제공된 영상에서 확인되는 조명 색 전환, 출시일은 2026년 11월 10일, CTA는 ‘출시 알림 신청’이야. 제품 사진·실제 사용 클립·승인 로고를 사용해. 0~1.5초에 조명의 구별되는 세부와 브랜드 단서, 4~7초에 전체 제품 리빌, 8.5~12초에 날짜와 CTA를 배치해. 부분 인서트 → 작은 푸시인 → 마스크 리빌 1회 → 로고 선 드로우 → 날짜·CTA 정지 조합을 써. 섬광·스트로브·과도한 카메라 회전을 넣지 마. 날짜는 처음부터 완성된 값으로 보여 줘. 장면표에 리빌 전후 정지 화면, 효과 시간·배율·이징, 사운드 큐, 자막, 저모션 대안을 포함해. 무음으로 제품명·일자·신청 행동이 전달되는지 검수해.

### 예시 3. 6초 서비스 범퍼와 훅 비교

> 이 루트의 A 템플릿으로 가상 파일 정리 서비스 ‘파일핏’의 6초 YouTube 범퍼를 제작해. 30fps 기준 총 180프레임으로 맞춰. 약속은 ‘흩어진 문서를 한곳에’, CTA는 ‘자세히 보기’ 하나야. 승인된 실제 폴더 정리 화면만 사용하고 자동화 범위·속도·절감률을 추가로 주장하지 마. 결과 인서트 → 제품 리빌 → 짧은 로고 스팅 → CTA 정지 조합을 써. 4.4~6.0초에는 CTA 진입 0.2초와 정지 1.4초를 배치하고, 문구가 읽히지 않으면 스팅을 줄여. 첫 1초만 ‘흩어진 폴더’와 ‘정리된 결과’로 다르게 만든 두 버전을 제시하고 나머지 장면·길이·CTA·음향은 동일하게 유지해. 비교할 지표와 플랫폼의 실제 집계 정의를 기록해. 6초 범퍼의 완주율만으로 구매 효과를 판정하지 말고, 제품·약속·행동 회상도 확인해. 무음·작은 화면·최종 로고 가독성을 검수해.

프롬프트에 등장하는 서비스·제품과 출시일은 지시문 예시용 설정이야. 실제 작업에서는 승인된 제품 정보·소재·일자로 교체해. 입력이 부족하면 주장을 발명하지 말고 확인이 필요한 값을 표시해.

## 6. 체크리스트와 완성 판정

완성은 ‘화려한가’가 아니라 **대상 시청자가 제품, 이익, 증거, 다음 행동을 재생 환경에서 이해할 수 있는가**로 판단해. 아래 표에서 필수 항목을 통과하고, 조건부 항목은 해당 여부와 확인 결과를 남겨.

| 판정 | 검사 항목 | 통과 조건 |
| :--- | :--- | :--- |
| 필수 | 목적·대상·CTA | 대상과 목표 행동을 각 한 문장으로 기록. 최종 CTA 동사 하나 |
| 필수 | 첫 프레임 | 검은 화면·의미 없는 장식만으로 시작하지 않음. 문제·제품·결과 중 하나가 보임 |
| 필수 | 브랜드·제품 식별 | 초반 브랜드 단서 존재. 제품 범주와 이름을 알 수 있는 시점 기록 |
| 조건부 | 건너뛰기 지면 | 5초 전에 제품과 가치 약속 이해 가능. 해당 지면이면 반드시 확인 |
| 필수 | 약속·증거 대응 | 시연이 주장한 기능·결과를 보여 줌. 과장된 비교나 가짜 성능 없음 |
| 조건부 | 수치·가격·날짜 | 원자료·조건·단위·기간·확정 값 대조. 확인 불가 수치 제거 |
| 필수 | 효과 예산 | 비트별 주효과와 보조 강조 기록. 효과를 쓰는 이유를 말할 수 있음 |
| 필수 | 실제 읽기 홀드 | 애니메이션 완료 후 읽는 시간 존재. 실제 크기·속도로 제품명·CTA·조건 판독 가능 |
| 필수 | 무음 재생 | 제품·이익·CTA를 음성 없이도 이해. 음향 전환 의미는 화면 문구로 보완 |
| 조건부 | 자막·음성 설명 | 음성이 있으면 발화·의미 있는 소리 자막 확인. 중요한 시각 정보의 음성 설명 여부 검토. [S5][S10] |
| 필수 | 대비·안전 영역 | 움직이는 장면에서도 필수 문구 대비 유지. 실제 게재 UI가 자막·CTA를 덮지 않음. [S2][S6] |
| 필수 | 섬광·저모션 | 전면 플래시·적색 스트로브 없음. 큰 이동 제거 시 제품·최종 값·CTA 보존. [S7][S9] |
| 조건부 | 웹 자동 재생 | 자동·5초 초과·병렬 콘텐츠 조건 확인. 해당하면 정지 제어 작동. [S8] |
| 필수 | 타이밍·출력 | 구간 합계가 목표 길이와 일치. 컷 경계·중간 프레임·끝 프레임에 빈 화면·잘림 없음 |
| 조건부 | QR·도착 위치 | 행사 QR은 실제 거리에서 스캔 가능. 모바일은 게시물 링크·프로필 등 실제 행동 경로 제공 |
| 필수 | 내용 이해 검수 | 브리프를 모르는 검수자에게 1회 재생 후 ‘무슨 제품·어떤 이익·무엇을 할지’ 확인. 틀린 항목 수정 후 다시 확인 |
| 권장 | 비교 실험 | 훅 또는 리빌 한 변수만 바꿈. 노출 조건·플랫폼 지표 정의 기록. 유지율 하나를 전환 성공으로 대체하지 않음 |

검수 기록 형식: `항목 / 해당 여부 / 통과·수정 필요 / 확인 환경 / 관찰 결과 / 수정 내용`. 미해당 항목은 이유를 적어. 모든 필수와 해당 조건부 항목이 통과해야 완성으로 표시해. 비교 실험의 지표·기준은 캠페인 목표에 맞춰 사전에 정하며, 이 문서에서 공통 CTR·시청률 목표를 발명하지 않아.

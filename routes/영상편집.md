# 영상편집: 설명·강의 영상의 모션 활용 루트

조사·웹 확인일: 2026-09-30. 대상: 설명·강의 영상의 컷 리듬, 전환, 자막, 화면 입력 시연, 도해 애니메이션, 나레이션 싱크.

핵심 루트: **학습 목표 → 시청 조건 → 의미 비트 → 확정 음성 → 읽기 예산 → 화면 상태 → 효과 조합 → 검수**. 움직임은 설명 대상·순서·변화·인과를 읽게 하는 데 배정해. 이해가 끝나기 전에 다음 화면으로 넘기지 마.

근거 표기: `[S]`는 끝의 웹 출처, `[L]`은 로컬 사전이야. 연구 원리·공식 규격과 제작 제안을 구분해. 별도 표시 없는 시간·거리·글자 크기·동기 오차는 **이 루트의 제작 시작값**이야. 학습 효과가 검증된 최적값이나 분석한 영상의 실측값으로 읽지 마. 블로그의 일반 팁·검색 요약은 근거로 채택하지 않았어.

## 2. 설계 로직

### 판단 순서

| 순서 | 먼저 정할 것 | 다음 단계로 넘길 산출 | 판단 규칙 |
| :--- | :--- | :--- | :--- |
| 1 | 대상의 사전 지식, 학습 후 할 행동·설명 | 목표 한 문장, 평가 과제 하나 | 초보면 부품 이름·전체 위치부터, 숙련자면 바로 과제와 예외부터 |
| 2 | 길이·비율·최소 시청 화면·소리·접근성 | 출력 조건, 자막·음성 설명 계획 | 영상이 짧아도 필수 조작·검증·자막을 생략하지 않아 |
| 3 | 질문·설명·시연·검증·회상 비트 | 비트별 핵심 하나와 이전/다음 상태 | 새 용어·새 조작·새 관계를 한꺼번에 처음 소개하면 분리해 |
| 4 | 실제 자료·입력·결과와 대본 | 출처·사실·예시 구분, 시연의 인과 순서 | 클릭·응답·결과를 재배열해 성능·인과를 왜곡하지 않아 |
| 5 | 나레이션과 의미 큐 | 확정 음성의 타임코드, 자막 초안 | 대본 가독성과 발음을 먼저 고쳐. 음성이 바뀌면 큐·자막·장면 길이를 다시 계산해 |
| 6 | 읽기·조작·생각 시간 | 완성 상태 홀드, 질문 대기, 총 길이 | 시간이 부족하면 문구·범위를 줄이거나 길이를 늘려. 먼저 음성을 가속하지 마 |
| 7 | 고정 화면 배치·핵심 대상 | 시선 목표, 라벨·자막 공간, 전체/확대 구도 | 한 비트의 주효과 하나와 보조 강조 하나부터 시작해. 인과에 필요한 순차 동작은 이어서 써 |
| 8 | 상황에 맞는 효과와 경계 | 컷·전환·카메라·강조·오디오 큐시트 | 기본은 하드 컷. 위치 연결·시간 생략·비교 등 이유가 있을 때 다른 효과를 추가해 |
| 9 | 검수와 수정 | 설계 통과/렌더 통과/시청 검토 상태 | 읽기·인과·접근성 미달이면 효과를 줄이고 홀드를 늘려 |

편집 리듬은 **설명 → 변화 → 정착 → 읽기/추론 → 다음 의미**로 잡아. 문장의 의미 경계, 대상 변경, 행동 완료에서 컷을 검토해. 같은 도해에서 관계를 설명하는 동안에는 컷 없이 유지해도 돼. 음악 박자·고정 3초 컷을 읽기와 학습 순서보다 우선하지 마. [S1·S2·S3·L2]

| 통계·측정 결과를 설명 | 고정 축·단위 + 막대 성장 + 최종 정확값 | 조건·단위 표시 → 성장 → 정확값 정지 | 애니메이션 중간값은 보간이야. 바운스·수치 오버슈트는 사실 왜곡 위험 [L3] |
| 새 장·시간·상태를 구분 | 하드 컷 + 챕터 라벨, 시간 경과에는 짧은 디졸브 선택 | 이전 정보 읽기 완료 → 경계 → 새 장 정착 | 전환의 의미를 통일해. 디졸브로 UI 글자가 겹치면 컷 사용 [S3·L2] |

| 결론에서 학습 전후를 연결 | 처음 질문 콜백 + 완성 도해 + 행동 한 줄 | 첫 질문 회수 → 답 → 다음 실습 | 형태 반복보다 실제 해결·전이를 보여 줘 [S1·L2·L4] |

### 나레이션·자막·시연 싱크 계약

| 큐 종류 | 기준 시점 | 동기 규칙 |
| :--- | :--- | :--- |
| 의미 큐 | “추가된다”, “연결한다” 등 핵심 동사·대상 발화 | 대응하는 변화의 의미 시점을 발화에 맞춰. 시작/도착/완료 중 무엇을 맞췄는지 기록해 |
| 동작 큐 | 실제 클릭·전송·입력 완료·결과 표시 | 녹화의 행동 시점을 보존해. 커서·링·설명은 여기에 맞춰 |
| 자막 큐 | 발화 시작·끝, 화자·의미 단위 | 전체 발화 의미를 담고 안정적으로 교체해. 주석은 자막과 별도 층으로 둬 |
| 전환 큐 | 의미 비트 경계와 오디오 연결 목적 | J 컷은 다음 음성 선행, L 컷은 이전 음성 잔류. 서로 다른 발화 두 개를 겹치지 않아 |
| 홀드 큐 | 완성 정보가 가림 없이 보이는 첫 프레임 | 리빌·타이핑·줌 시간을 완성 상태 읽기 시간에 포함하지 마 |

큐시트에는 `시작초 / 종료초 / 핵심 발화 / 의미 사건과 기준점 / 화면 전후 상태 / 효과·시간·이징 / 자막 / 완성 홀드 / 근거·생략 표시`를 적어. 의미 동기 오차는 ±0.10초를 검토 목표로 시작하되 연구가 입증한 지각 임계값으로 쓰지 마. 컷·클릭·자막은 출력 fps의 프레임 경계로 정렬해. [S2·S6·L4]

## 3. 구조 템플릿 3개

모든 구간은 절대 시간의 초야. 표의 길이에 전환·홀드·질문 대기가 포함돼. 최종 음성이 길면 전체 시간을 다시 잡아. 장면 길이와 모션 지속 시간은 서로 다른 값이야. 아래 배치는 제작 제안이며 연구·사례의 실측 타임라인은 아니야.

### A. 90초: 개념 하나를 설명하는 영상

| 구간 | 비트·발화 역할 | 효과 배치·타이밍 | 정착·읽기 |
| :--- | :--- | :--- | :--- |

조합: 컷 + 점진적 공개 + 연결선 + 단어 강조. 제목 키네틱 타이포는 훅에만 선택해. 과정 설명 중에는 카메라와 본문을 고정해. [S1·S2·L3·L4]

## 4. 권장 효과와 파라미터 범위, 피할 것

### 공통 파라미터 계약

| 구분 | 값·정의 | 적용 범위 |

| 음성 설명 | 대상 이름·변화·결과·차이를 발화 | 시각 정보 누락을 대본 단계에서 보완하고 필요하면 추가 해설 [S7] |

## 5. 에이전트 프롬프트 예시 3개

### 예시 1: 90초 개념 설명

> 이 루트의 A 템플릿으로 ‘언어 모델은 다음 토큰을 예측한다’를 설명하는 16:9·1080p·90초 영상 설계안을 만들어. 대상은 AI 용어가 낯선 직장인이야. 목표는 입력·예측·추가의 관계와 ‘예측이 사실 확인을 보장하지 않는다’는 한계를 자기 말로 설명하는 거야. 새 용어는 토큰·컨텍스트만 먼저 소개해. 고정 도해에 점진적 공개·연결선·현재 단계 강조를 조합하고, 마지막에 조건을 바꾼 예측 질문을 넣어. 절대 초 타임라인·발화·의미 큐의 기준점·자막·효과 시간·이징·완성 홀드를 표로 출력해. 음성이 아직 없으면 시간표를 초안으로 표시해. 후보 확률·모델 결과를 임의 실측값으로 만들지 말고 설명용 예시를 표시해. 제작 제안과 출처 근거, 읽기 예산, 모션을 줄인 대안, 실제 렌더에서 확인할 항목을 함께 적어.

### 예시 2: 180초 화면 입력 시연

> 제공한 실제 화면 녹화·음성·원문 자료로 ‘회의록에서 결정 사항을 추출하고 원문으로 검증하기’ 180초 영상을 B 템플릿에 맞춰 편집 설계해. 전체 화면→입력창 확대→핵심 조건 입력→실행→결과→원문 비교 순서를 유지해. 원본의 클릭·응답 타임코드를 먼저 확인하고, 긴 대기만 점프컷과 생략 표시로 압축해. 새로 그린 커서는 실제 행동과 구분해. 자막은 발화·중요 소리·화자를 반영하고 부정어·수치·조건을 수동 검토해. 원본 소스 구간과 출력 타임코드를 대응시키고 효과·이징·읽기 홀드·가림 여부를 표로 써. 잘못된 출력은 검증 장면에 남겨. 자료가 없으면 성공 결과를 꾸미지 말고 필요한 입력과 미확인 상태를 적어. 폰 독해·무음·음성만 청취·전환 경계 검사를 완성 판정표에 포함해.

### 예시 3: 300초 미니 강의 편집

> 이 루트의 C 템플릿으로 ‘좋은 프롬프트와 결과 검증’ 300초 미니 강의 편집안을 만들어. 목표는 학습자가 역할·자료·출력 형식을 정하고 결과를 원문과 대조하는 거야. 초보 대상, LMS·데스크톱과 폰 재생, 발화 자막과 주요 시각 결과의 음성 설명이 필요해. 확정 대본·음성·실제 UI 자료를 기준으로 개념→시연→반례→새 사례 적용 순서를 설계해. 장면마다 주효과 하나와 보조 강조 하나부터 고르고, 고정 컷 빈도를 강제하지 마. 의미 큐·J/L 컷의 선행/잔류·챕터·자막 읽기 예산·완성 도해 홀드·질문 대기를 포함한 초 단위 큐시트를 출력해. 300초에 독해가 안 되면 축소할 범위 또는 필요한 연장 시간을 제안해. 연구·공식 규격·제작 제안을 구분하고 렌더 확인 전에는 납품 완료로 선언하지 마. 최종 검수에는 영상 뒤 개념 질문과 같은 과제 수행을 포함해.

| 시청 검토 | 음성만 | 대상·핵심 시각 변화·결과·차이를 이해할 수 있어 | 주 음성·음성 해설 보완 |

| 납품 | 재참조·파일 | 챕터·자막 트랙/번인 방침·완성 요약·실습 자료·출력 조건 확인 | 매체별 출력·자료 보완 |

# 쇼츠·릴스·카드뉴스 영상 모션 활용 루트

조사·확인일: 2026-09-30. 대상: 9:16 세로 피드 영상, 첫 1초 훅, 빠른 템포, 한국어 캡션.

목적: 주제·대본·소재에서 **무엇을 먼저 보여 주고, 언제 멈추고, 어떤 효과를 조합할지** 결정해. 개별 효과 정의는 로컬 사전으로 연결해.

근거 표기: S는 웹 원출처, L은 로컬 사전이야. 공식 요구·공식 권고·연구 결과·제작 제안을 구분해. **별도 표시가 없는 시간·거리·크기·빈도와 템플릿은 이 루트의 제작 시작값**이야. 검증된 최적값이나 성과 보장으로 읽지 마.

### 캡션을 먼저 확보해

1. 제목·강조 타이포와 접근성 캡션을 구분해. 제목은 관심 유도, 캡션은 실제 발화와 이해에 필요한 소리를 전달해. 핵심어만 튀는 화면으로 전체 캡션을 대체하지 마 [S4·L3].
2. 뜻 단위 1~2줄, 한 줄 10~16자 상당부터 시험해. 조사·숫자와 단위·부정어를 떼지 마. 한글 음절 내부를 쪼개지 마 [L3].
3. Netflix 한국어 번역 자막 기준은 한 줄 16자·최대 2줄·성인 최대 12자/초·아동 최대 9자/초야. 한국어 SDH는 성인 최대 14자/초·아동 최대 11자/초로 별도 제시돼. 라틴 문자·공백·문장부호는 0.5자로 계산해. Netflix 납품 기준이지 쇼츠 의무나 모든 사람의 읽기 속도는 아니야 [S9].
4. 이 루트는 성인 10~12자 상당/초, 아동·초보자 8~9자 상당/초를 보수적 시작값으로 써. `완성 상태 가시 시간 ≥ 글자 상당 수 ÷ 목표 속도`로 검사해. 새 용어·도표가 함께 있으면 늘려. 24자 상당은 12자/초에서 최소 2초가 필요하고 200ms 등장은 그 2초에 포함하지 마.
5. 발화가 읽기 예산을 넘으면 대본을 줄이거나 영상을 늘려. 발화 캡션에서 의미를 누락해서 길이를 맞추지 마. 편집 후 음성·캡션을 함께 다시 맞춰.
6. 1080×1920에서 캡션 52~72px, 제목 80~120px, 캡션 행간 1.15~1.35부터 시험해. 공식 글자 크기가 아니야. 배경판·외곽선은 밝고 어두운 장면 모두에서 검사해.
7. 캡션 위치를 안정적으로 유지해. 충돌하면 장면 시작 전에 옮기고 읽는 중 이동시키지 마. 별도 CC가 있으면 화면 삽입 캡션과 중복 노출도 확인해.

참고: [Netflix 한국어 자막](https://partnerhelp.netflixstudios.com/hc/en-us/articles/216001127-Korean-Timed-Text-Style-Guide), [W3C 캡션 설명](https://www.w3.org/WAI/WCAG22/Understanding/captions-prerecorded.html).

## 2. 설계 로직

**시청자·기억할 주장 → 플랫폼·길이·소재 → 결과/문제 훅 → 캡션·읽기 예산 → 증거 비트 → 효과 조합 → 오디오·전환 → 실제 화면 검수 → 훅 비교 실험** 순서로 정해.

| 순서 | 먼저 정할 것 | 다음 단계 조건 |
| :--- | :--- | :--- |
| 1 | 시청자·사전 지식·기억할 한 문장·저장/실행/방문 중 행동 하나 | 주장이 구체적이고 근거로 뒷받침돼 |
| 2 | 플랫폼·일반 게시/광고·총 길이·원본·데이터 출처 | 세로 구도와 안전영역에 필수 대상이 들어가 |
| 3 | 완성 결과·오류·전후 차이 중 훅 하나 | 첫 1초 관심 이유·첫 3초 제안이 보여 |
| 4 | 실제 대본·발화 시간·캡션 뜻 단위·카드 읽기 시간 | 예산이 총 길이에 들어가. 넘치면 효과보다 대본부터 줄여 |
| 5 | 비트 역할: 관심/약속/증거/정리 | 모든 비트가 주장에 기여해 |
| 6 | 비트별 주효과 1개·보조 강조 최대 1개 | 주요 시선 대상이 한 곳이야 |
| 7 | 컷 지점·발화 연결·음악·효과음 | 읽기와 발화가 음악 박자보다 우선이야 |
| 8 | 0초·1초·전환 중간·완성·마지막 화면 | 가독성·정확성·읽기 홀드가 통과해 |
| 9 | 훅 A/B·관찰 지표 | 본론·대상·조건을 가능한 한 맞춰 비교해. 표본 부족이면 우열을 단정하지 마 |

### 상황 → 효과·조합 결정표

| 상황 | 쓸 효과·조합과 순서 | 이유·근거 |
| :--- | :--- | :--- |
| 결과가 한눈에 매력적이야 | 0초 완성 결과 고정 → 제목 마스크 리빌 → 방법으로 하드 컷 | 초반 제안 권고를 결과 선공개에 적용한 제작 추론이야 [S1] |
| 오해를 깨야 해 | 오해 문장 → 반례로 스매시 컷 → 근거 하이라이트 | 내용 대비로 관심을 만들어. 플래시·폭발음은 필수가 아니야 [L2] |
| 말하기가 늘어져 | 문장 끝 점프컷 → 관련 인서트 → 안정 캡션의 발화 동기 강조 | 군더더기를 줄이고 증거를 보여 줘. 부정어·조건·핵심 행동은 남겨 [L2·L3] |
| 시연 버튼이 작아 | 전체 구도 → 확대 콜아웃 → 클릭 리플 → 결과 홀드 | 어디의 세부인지 유지하면서 조작과 결과를 읽게 해 [L3] |
| 전후 비교야 | 같은 구도·축척·A/B 라벨 → 와이프 → 차이 하이라이트 → 홀드 | 비교 기준을 대응시켜. 와이프 중 본문 변경은 피하고 동일 위치를 유지해 [L2] |
| 단계 카드야 | 고정 번호 → 같은 방향 푸시 → 제목 → 핵심 한 줄 → 홀드 | 방향은 순서, 번호는 현재 위치를 알려 줘. 독립 팁이면 컷을 써 [L2·L4] |
| 수치 크기 비교야 | 축·단위·출처 고정 → 막대 성장 → 정확값·차이 주석 → 홀드 | 움직임은 시선 단서로 써. 비교 완료 전에 컷하지 마 [L3] |
| 실제 시계열이야 | 실제 시점 라벨 → 선 그리기/점 이동 → 마지막 값 주석 | 보간을 실측처럼 보이지 않게 해. 전후 값만 있으면 두 막대로 바꿔 [L3] |
| 새 용어·원리야 | 이름 먼저 → 도해 한 요소씩 리빌 → 연결선 → 한 문장 정리 | 분절·단서 원리를 적용한 제안이야. 빠른 정보 폭주를 피해야 해 [S7·L4] |
| 에너지 있는 장소 이동이야 | 문장 완료 → 휩팬 1회 → 구도 정착 → 읽기 | 강한 이동은 드문 의미 전환에만 배정해. 표·정의·시연에는 컷을 써 [L2·S10] |
| 다음 설명으로 연결해 | J/L 컷 + 인서트/컷어웨이 + 발화 기준 캡션 유지 | 화면과 말의 경계를 분리해 맥락을 이어. 무음에는 예고/근거 라벨을 남겨 [L2] |
| 읽기 어려워 | 효과 제거 → 카드 분할 → 완성 홀드 연장 | 빠른 템포는 불필요한 대기를 줄이는 목표야. 이해 시간을 없애지 마 [S7·L3] |

조합 기본: **등장 → 정착 → 보조 강조 → 읽기 → 교체**. 제목 리빌과 작은 배경 움직임은 겹칠 수 있어. 도해 등장·차트 변화·카메라 줌은 분리해. 같은 의미에는 같은 방향·강조색·이징을 써.

연구 적용 한계: Mayer·Moreno는 학습과 전이 과제를 다뤘고 피드 완주율 실험은 아니야. 학습자 제어 분절 결과를 자동 재생 영상의 특정 초 단위 처방으로 일반화하지 마. 중복 제거를 캡션 삭제 근거로 쓰지 말고 캡션 외의 반복 본문·장식을 줄여 [S7·S4].

## 3. 구조 템플릿

구간은 최종 영상 절대 시간이야. 효과·전환을 구간 안에 포함하고 뒤에 별도 시간을 더하지 마. 읽기 예산이 넘치면 문구를 줄이거나 길이를 늘려.

### A. 15초 결과 선공개형

사용: 제품 결과·전후 변화·한 가지 팁. 훅의 결과와 본론의 증거가 같은 주장이어야 해.

| 시간 | 비트 | 효과 배치·홀드 |
| :--- | :--- | :--- |
| 0.0~1.0초 | 훅: 완성 결과·관심 문구 | 결과 0초부터 고정. 제목 0.0~0.2초 마스크 리빌. 읽기 예산이 필요하면 다음 비트까지 문구 유지 |
| 1.0~3.0초 | 약속: 얻을 결과·조건 | 컷 또는 같은 화면 유지, 핵심어 150ms 강조. 나머지는 읽기 |
| 3.0~7.0초 | 본론 1: 핵심 행동 | 전체 구도 → 3.3~3.6초 콜아웃 → 클릭 150ms → 결과 고정 |
| 7.0~11.0초 | 본론 2: 증거 | 7.0초 컷 → 7.2~7.5초 하이라이트 → 결과 홀드 |
| 11.0~15.0초 | 정리·행동 하나 | 컷 또는 200ms 페이드. 결론·조건 유지, 끝 1.5초에는 새 정보 금지 |

선택: 전후 비교라면 7.0~7.4초 와이프 후 홀드로 바꿔. 축 변경·수치 과장·최종값을 숨기는 카운트업은 빼.

### B. 30초 말하기·시연형

사용: 튜토리얼·오류 해결·짧은 설명. 반복·대기만 줄이고 필수 행동 순서는 보존해.

| 시간 | 비트 | 효과 배치·홀드 |
| :--- | :--- | :--- |
| 0.0~1.0초 | 훅: 오류/결과 + 얼굴 | 오류/결과 즉시 고정, 제목 150ms 등장 |
| 1.0~3.0초 | 약속: 해결 대상·범위 | 안정 캡션, 핵심어 하나 100~150ms 배경 강조 |
| 3.0~9.0초 | 단계 1: 원인 | 시연 화면 컷 → 3.3~3.7초 콜아웃 → 3.8~4.1초 밑줄 → 설명 홀드 |
| 9.0~16.0초 | 단계 2: 수정 | 컷 → 커서 → 클릭 리플 → 핵심 입력. 대기 생략은 표시한 점프컷 |
| 16.0~24.0초 | 단계 3: 검증 | 결과 인서트 + 필요하면 L 컷 200~400ms. 16.4~16.7초 차이 강조 후 결과·검증 기준 고정 |
| 24.0~30.0초 | 요약·실행 제안 | 2~3항목 스태거, 전체 400ms 안에 완성. 최종 상태 최소 3초 유지 |

선택: 얼굴 펀치인 1~2회는 핵심 발화에만 배정해. 캡션 레이어는 확대하지 마. 카메라·커서·자막이 같이 튀면 펀치인을 제거해.

### C. 24초 카드뉴스형

사용: 저장용 팁 3개·짧은 절차. 기사 본문을 페이지째 축소하지 마.

| 시간 | 비트 | 효과 배치·홀드 |
| :--- | :--- | :--- |

## 5. 에이전트 프롬프트 예시 3개

### 예시 1: 결과 선공개 15초 팁

> 이 루트를 적용해 9:16·1080×1920·15초 영상 설계안을 만들어. 주제는 ‘엑셀 중복값 찾기’, 대상은 초보 직장인이야. 첫 프레임에 실제 중복 셀 결과를 보여 주고 1초 안에 관심 이유, 3초 안에 얻을 결과를 제시해. A 템플릿으로 절대 시간별 화면·발화·캡션·효과·이징·완성 홀드를 표로 써. 컷·확대 콜아웃·하이라이트를 조합하고 캡션은 뜻 단위 1~2줄과 핵심어 배경 강조를 써. 성인 10~12자 상당/초 시작값으로 읽기 예산을 검사해. 대기 생략을 표시하고 실제 결과를 과장하지 마. 안전영역·실제 UI를 확인하기 전에는 검수 완료로 쓰지 마. 모션을 줄인 대안과 훅 문구 A/B도 제시해.

### 예시 2: 저장용 카드뉴스 24초

> C 템플릿으로 ‘회의록을 읽기 쉽게 쓰는 3가지’ 카드뉴스 영상을 설계해. 9:16·24초, 내레이션 없이 텍스트로 의미를 완결해. 0초부터 주제·이득을 보여 주고 카드별 행동 하나·짧은 예시만 넣어. 독립 팁이라 하드 컷으로 통일하고 제목 마스크·항목 스태거·밑줄만 조합해. 한국어 줄바꿈·글자 크기·카드별 완성 상태 가시 시간·읽기 예산을 표로 명시해. 마지막 요약이 3초에 읽히지 않으면 문구를 줄이거나 총 길이를 늘려. 플랫폼 UI 검수 항목과 미확인 항목을 구분하고 정적 카드 요약 구성도 적어.

### 예시 3: 근거 있는 데이터 비교 30초

> 제공한 원자료로 ‘두 방식의 작업시간 차이’를 설명하는 9:16·30초 영상 설계안을 만들어. 원자료 출처·측정 조건·단위·표본·차이 계산부터 확인해. 부족하면 결과 수치를 만들지 말고 미확인 입력을 표시해. D 템플릿으로 첫 1초에 완성 비교를 보여 줘. 축·단위·A/B는 고정하고 막대 성장 400~800ms 뒤 정확값을 2초 이상 읽게 해. 수치 오버슈트·중간값 실측 암시·근거 없는 인과를 금지해. 캡션은 발화 동기 강조, 카메라는 고정이야. 핵심 시각 결과는 음성으로도 설명해. 타임코드·읽기 예산·효과 선택 이유·출처 위치·접근성 검사·완성 판정표를 출력해.

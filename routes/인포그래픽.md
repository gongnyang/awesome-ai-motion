# 인포그래픽 모션 활용 루트

조사일·웹 확인일: 2026.09.30 · 대상: 정지·움직이는 인포그래픽 편집, 데이터 강조, 주석 등장, 전후 비교, 노션·웹 삽입

핵심 루트: **읽을 최종 화면부터 완성 → 독자의 질문과 비교 대상을 고정 → 정적으로 해결되는지 판단 → 변화 추적에 필요한 부분만 움직임 → 읽기 홀드와 사용자 제어 → 정적 대안 검수**.

근거 표기: [R]은 연구, [G]는 공식 가이드·접근성 기준, [L]은 로컬 사전. **[P]는 이 루트의 제작 시작값·설계 제안**이야. 초·px·개수 범위는 연구에서 증명한 최적값이나 접근성 보장값이 아냐. 실제 표시 크기·문장 길이·데이터 복잡도에 맞춰 조정해. 출처 ID의 URL과 날짜는 문서 끝에서 확인해.

## 2. 설계 로직

### 판단 순서

1. **한 문장 주장 작성**: “어떤 기간·집단에서 무엇이 얼마나 달라졌나”로 써. 탐색용이면 주장 대신 독자의 질문을 써. 데이터 출처·관측일·단위·분모·결측·불확실성부터 확인해.
2. **최종 정지 화면 설계**: 제목 → 차트 → 직접 라벨 → 핵심 주석 → 출처·조건 순으로 위계를 잡아. 마지막 상태 하나로 핵심 질문에 답하지 못하면 모션을 붙이기 전에 수정해.
3. **매체·제어 분기**: 정지 파일이면 공간적 순서로 끝내. 웹·노션이면 임베드 가능 여부와 정지·단계 제어부터 확인해. 제어 불가 자동 반복이면 정적으로 되돌려.
4. **과제 분기**: 정확값 조회·다항목 비교는 정적 병렬 우선. 동일 항목의 변화 추적이면 객체 유지 전환. 집계 원리면 단계 리빌. 관심 유도만 필요하면 고정 차트에 국소 강조 하나.
5. **변화 계약 고정**: 전후 id·단위·축 범위·분모를 기록해. 같은 항목이 아니면 모프 금지. 필터·정렬·축 변경이 겹치면 의미 변화별로 분리하고 변경 사실을 표시해 [R1].
6. **효과 조합 선택**: 한 비트에 주요 변화 하나, 보조 강조 하나부터 시작해 [P·L2]. 차트 이동 중에 새 문장을 읽히지 말고 도착 → 주석 → 홀드로 나눠.
7. **시간·대안 배치**: 등장 시간보다 읽기 시간을 먼저 확보해. 독자가 값·단위·결론을 읽지 못하면 홀드 연장·문장 축약·장면 분리. 웹은 기다림 대신 다음·이전 단계로 해결해.
8. **완성 판정**: 정지·모션 축소·모바일·역방향 탐색에서 같은 결론과 정확값이 남는지 확인해. 해결 못 하면 해당 효과를 제거해.

흐름: **질문·데이터 → 최종 정지 화면 → 매체·제어 → 조회 / 비교 / 추적 / 과정 분기 → 불변 요소 확정 → 주요 효과＋보조 효과 → 홀드·정적 대안 → 검수**.

| 1 | 상단 주장＋기간·집단 | 짧은 제목, 핵심어 한 곳만 색·밑줄 강조 |
| 2 | 중앙 차트 또는 전후 병렬 | 동일 축·단위, 정확값 직접 표시 |
| 3 | 데이터 외곽의 주석 1~2개 | 연결선·테두리·완성된 하이라이트 |
| 4 | 하단 출처·분모·정의·예외 | 본문에서도 읽을 수 있는 설명·표 링크 |

정지판에 애니메이션의 중간값·미완성 막대·사라진 이전 상태를 남기지 마. 주석 없이 읽으면 다른 결론이 나오는지 먼저 확인해.

### B. 주석으로 핵심 찾기, 12초

적합: 완성 차트에서 한 구간의 의미를 설명. 차트 본체는 계속 고정.

| 시간 | 비트 | 효과·조합 |
| --- | --- | --- |
| 0.0~2.0초 | 훅·읽을 질문 | 완성 차트·제목·축·단위 모두 보임. 질문 문장 고정 |
| 2.0~2.3초 | 대상 지목 | 목표 점·구간에 테두리 또는 밑줄 300ms |
| 2.3~2.6초 | 관계 연결 | 연결선 draw 300ms |
| 2.6~2.8초 | 주석 등장 | 주석 fade 200ms, 최대 두 줄부터 검토 |
| 2.8~7.0초 | 해석 읽기 | 모든 요소 정지. 정확값과 조건 함께 확인 |
| 7.0~7.4초 | 결론 강조 | 제목의 핵심어 한 곳 스윕 400ms |
| 7.4~12.0초 | 정리 | 차트·주석·결론·출처를 고정한 채 끝냄 |

웹 적용: 초기에는 완성 차트와 설명을 읽게 해. 별도 “강조 보기” 동작이 있을 때만 강조 순서 재생. 자동 재생을 택하면 [G2] 조건을 확인해. 모션 축소는 최종 주석을 즉시 제공.

### C. 전후 변화 비교, 16초

적합: 동일 집단·동일 단위의 두 시점. 정확값 비교는 마지막 병렬 화면에서 수행.

| 시간 | 비트 | 효과·조합 |
| --- | --- | --- |
| 0.0~2.0초 | 훅·비교 약속 | 질문＋전·후 기간 라벨＋공통 축 |
| 2.0~4.0초 | 이전 상태 읽기 | 이전 값 고정, 비교 대상 한 쌍 표시 |
| 4.0~4.8초 | 변화 추적 | 같은 id의 점·막대 보간 800ms, 축·카메라 고정 |
| 4.8~7.0초 | 이후 상태 읽기 | 새 정확값 고정. 중간 상태가 실측이 아님을 구분 |
| 7.0~7.2초 | 비교 화면 전환 | 컷 또는 짧은 fade로 준비된 전후 병렬 요약을 공개 |
| 7.2~7.7초 | 차이 설명 | 차이 라벨·주석 500ms 이내, 대상과 연결 |
| 7.7~16.0초 | 정리·검증 | 전·후 정확값＋절대 차이·상대 변화＋단위·출처 고정 |

비율 지표는 %와 %p를 구분해. 예: 30% → 45%는 ＋15%p, 상대 변화 ＋50%. 기준값 0이면 상대 변화율을 임의로 만들지 마. 모션 축소는 처음부터 전후 병렬과 차이 라벨 제공.

### D. 집계 과정 설명, 24초 또는 수동 4단계

적합: 필터·그룹·평균·합계가 최종 차트로 이어지는 설명. 데이터 변환에 의미가 있을 때만 선택 [R3].

| 시간 | 비트 | 효과·조합 |
| --- | --- | --- |
| 0.0~3.0초 | 질문·분석 약속 | 원자료·단위·집계할 질문 고정 |
| 3.0~3.6초 | 1단계 필터 | 선택 테두리 200ms → 제외 요소 fade 400ms. 제외 조건·남은 n 표시 |
| 3.6~7.0초 | 1단계 홀드 | 선택된 원자료를 읽음. 제외는 값 0과 구분 |
| 7.0~7.8초 | 2단계 묶기 | id 유지 그룹 이동 800ms, 그룹명 고정 |
| 7.8~11.0초 | 2단계 홀드 | 묶음 기준·그룹별 n 표시 |
| 11.0~11.8초 | 3단계 집계 | 대응선·집계 결과 등장 800ms. 수식·분모·결측 처리 표시 |
| 11.8~16.0초 | 3단계 홀드 | 합계·평균·비율 중 무엇인지 확인 |
| 16.0~16.6초 | 4단계 최종 차트 | 계산된 결과에 대응하는 막대·점 공개 600ms |
| 16.6~24.0초 | 정리 | 질문의 답＋완성 차트＋집계 규칙＋출처 고정 |

웹은 “원자료 / 필터 / 묶기 / 집계·결과” 단계 버튼과 이전·다음 제공. 단계 전환은 600~800ms부터 검토하되 읽기는 무제한. 정적 대안은 네 단계 도해와 결과표. 표본 가중치·결측 처리 등 실제 집계 규칙을 모션 편의 때문에 바꾸지 마.

## 4. 권장 효과·파라미터·피할 것

### 공통 파라미터 계약

1. 단위: 시간은 ms, 위치·선 두께는 **실제 표시 화면의 CSS px 기준** [P]. 1920px 원본을 320px로 줄일 때 원본 px를 그대로 가독성 기준으로 쓰지 마.
2. 읽기 홀드: 단순 제목 1.0~1.6초, 단순 차트·주석 1.8~3.0초부터 시작 [L2·P]. 표를 읽거나 비교 계산을 요구하면 더 길게 잡거나 사용자 제어로 전환해.
3. 이징: Carbon productive의 진입 E=`cubic-bezier(0,0,0.38,0.9)`, 상태 변화 S=`cubic-bezier(0.2,0,0.38,0.9)` 사용 가능 [G1]. L=`linear`는 시간 진행·스크럽에 사용. 로컬 사전의 키와 곡선이 다를 수 있으니 코드에 실제 곡선을 명시해.
4. 데이터 값은 공통 진행률 하나로 점·막대·라벨을 맞춰. 물리량의 시간 변화율을 읽어야 하면 시각 속도를 임의의 ease로 바꾸지 말고 실제 시간축·L을 사용 [P].
5. 모션 축소: 이동 0px·scale 1, 최종 상태 즉시 노출을 기본으로 해 [P·G3]. 옵션으로 짧은 fade를 사용해도 정보가 지연·누락되지 않는지 확인해.

## 5. 에이전트 프롬프트 예시 3개

### 예시 1. 노션용 정지 데이터 강조 카드

> 이 인포그래픽 루트의 템플릿 A로 노션 본문용 정지 카드를 만들어. 제공한 원자료와 출처만 사용해. 목표는 가장 큰 차이를 찾고 정확값·기간·단위를 읽는 거야. 주장 한 문장을 먼저 정하고, 같은 축의 비교 차트와 직접 라벨을 배치해. 핵심 한 쌍만 밑줄·테두리로 강조하고 주석은 두 개 이내로 써. 320px 표시 폭에서도 읽히게 구성해. 색 외 구분을 넣고 일반 글자 대비 4.5:1을 확인해. 완성 이미지와 함께 짧은 대체 설명, 상세 데이터표, 출처·확인일을 제공해. 제공 데이터에 없는 인과 설명이나 수치를 만들지 마. 마지막에 완성 체크리스트 결과를 알려줘.

### 예시 2. 무음 전후 비교 영상

> 이 루트의 템플릿 C로 16초 무음 전후 비교 인포그래픽을 만들어. 데이터는 동일 집단의 도입 전 30%, 도입 후 45%라는 가상 예시야. 화면에도 가상 예시라고 표시해. 축은 0~100%로 고정하고 id·색·단위를 유지해. 2초 이전 상태 홀드 후 800ms 보간하고, 마지막에는 전후 병렬·＋15%p·상대 변화 ＋50%를 정확히 표시해. 막대 길이와 숫자를 같은 진행률로 맞추고 보간을 실측 시계열로 표현하지 마. 카메라는 고정하고 주요 변화 하나와 보조 주석만 사용해. 0초·중간·끝 화면을 검수하고 최종 포스터와 설명문도 만들어. 시간값은 출발점이므로 실제 모바일 표시에서 읽기 부족하면 홀드를 늘려.

### 예시 3. 노션·웹 삽입용 집계 설명

> 제공한 CSV와 집계 규칙으로 이 루트의 템플릿 D에 해당하는 인포그래픽을 만들어. 원자료 → 필터 → 그룹 → 집계·결과의 네 상태를 사용자 버튼으로 탐색하게 해. 각 단계에 남은 n, 단위, 분모, 결측 처리 규칙을 표시해. 이동은 동일 id를 유지하고 의미가 다른 변화는 나눠. 자동 재생을 기본으로 켜지 마. 재생 기능을 넣으면 멈춤·이전·다음·전체 보기와 키보드 조작을 제공해. prefers-reduced-motion에서는 큰 이동 없이 동일한 값·주석을 읽게 해. 노션에는 실행 가능한 HTML 업로드를 가정하지 말고 호스팅한 HTTPS 임베드 URL 방식으로 준비해. 외부 로그인 없이 접근하는 상황과 320px·실제 임베드 폭에서 잘림·조작을 확인해. 임베드 불가 시 정지 포스터·결과표·원본 링크를 제공하고 확인하지 못한 환경은 검수 결과에 구분해.

## 6. 체크리스트: 완성 판정

모든 필수 항목이 통과해야 완성. 미확인 항목을 통과로 표시하지 마. 이 문서는 조사·설계 문서이며 실제 영상 렌더·노션 삽입 실험은 수행하지 않았어.

| 필수 확인 | 통과 조건 | 확인 방법 |
| --- | --- | --- |
| 질문·결론 | 독자가 무엇을 비교·해석해야 하는지 한 문장으로 설명 가능 | 최종 화면만 보고 질문에 답하기 |
| 데이터 정확성 | 원자료·최종값 일치, 단위·기간·집단·분모·결측·반올림 명시 | 입력과 결과표 대조, 예시값 표기 확인 |
| 증감 표현 | 차이·변화율·%p 구분, 기준값 0 예외 처리 | 전후 값을 직접 재계산 |
| 비교 정직성 | 크기 비교 막대 0 기준선, 전후 축 동일, 축 변경은 명시 | 시작·끝·병렬 화면 대조 |
| 변화의 의미 | 동일 id만 연결, 추가·삭제·필터는 구분, 중간값은 연출 보간 | 중간 프레임과 상태 정의 대조 |
| 강조·주석 | 강조가 결론과 일치, 축·값을 가리지 않음, 인과 주장에 근거 있음 | 주석 없는 화면과 의미 비교 |
| 읽기 | 실제 표시 크기에서 값·단위·조건을 읽을 수 있음 | 모바일·임베드 크기에서 무음 재생, 부족하면 홀드 연장 |
| 정지 대안 | 재생 없이 핵심 결론·전후·집계 규칙 확인 | 포스터·단계 도해·설명·표 검수 |
| 색·대비 | 색 외 구분과 적용 대상별 대비 충족 | 대비 계산, 흑백에서도 라벨·기호 확인 |
| 제어 | 필요한 정지·재생·단계 제어 제공, 키보드·터치로 동일 정보 접근 | Tab·Enter·방향키·터치, 재생 정지 후 본문 조작 |
| 모션 축소 | 이동·줌 제거 후에도 정확값·주석·제어 유지 | OS 설정과 미디어 쿼리 상태, GIF·영상의 별도 대안 확인 |
| 시간 탐색 | 시작·중간·끝·역방향에서 값·선택·라벨 일치 | 같은 시점으로 반복 이동, 누적 이벤트 오류 확인 |
| 임베드 | 실제 서비스에서 높이·줄바꿈·컨트롤 정상, 로그인·차단 실패 대안 있음 | 노션 웹·데스크톱·모바일 중 대상 환경에서 직접 확인 |
| 출처·기록 | 데이터 출처·관측일·조사 근거·확인일 표시 | 링크 열기, 갱신 데이터와 저장본 날짜 구분 |

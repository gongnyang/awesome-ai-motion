조사·확인일: 2026년 9월 30일. 대상: 제품·서비스 소개, 홍보 영상, 출시 티저, 훅, 제품 리빌, 로고 스팅, CTA. 결과물 형식: 효과 카탈로그를 실제 비트에 배치하는 판단 문서.

기본 루트: 목표 행동 1개 → 매체와 시청 환경 → 고객 문제와 가치 약속 → 보여 줄 증거 → 비트와 읽기 시간 → 효과 조합 → 접근성 대안 → 검수. 효과부터 고르지 않아.

근거 표기: 공식은 매체 가이드·표준의 직접 내용, 설계 제안은 그 내용을 소개·홍보 용도에 적용한 제작 시작값. 아래 초·이동량·효과 횟수는 별도 표시가 없으면 설계 제안이야. 특정 효과가 클릭률·구매율을 높인다는 보장으로 읽지 마. 플랫폼 연구는 해당 광고 환경의 결과이며, 서로 다른 매체와 브랜드에 그대로 일반화하지 않아.

로컬 사전은 실제로 있는 「00 한눈에」, 「2 전환·컷·카메라」, 「3 타이포와 데이터 애니메이션」을 참고했어. 목차에만 있는 「1 애니메이션 원칙과 모션 기본기」와 「4 설명 영상 연출과 학습 원리」는 본문을 확인하지 못했어. 기존 사전의 3~5분 설명 영상용 시간값을 짧은 광고에 그대로 옮기지 않고, 읽기 홀드와 조합 원칙을 가져왔어. [L1][L2][L3]

조합 예산

  1. 한 비트의 기본은 주효과 1개 + 보조 강조 1개 이하 + 읽기 홀드. 예: 제품 마스크 리빌 + 제품명 고정, 또는 UI 줌 + 주석 등장. 이 개수는 제작 통제용 제안이야.
  1. 카메라가 이동하는 동안 긴 카피·숫자 갱신을 추가하지 않아. 도착 → 주석 등장 → 읽기 순서로 분리해. 핵심어 1~2개 외에는 자막을 안정된 위치에 둬. 경쟁 요소 억제라는 공식 원칙을 적용한 조합이야. [S1][L3]
  1. 강한 브랜드 동작은 훅이나 리빌 중 한 곳을 주무대로 정해. 휩팬·글리치·큰 팝을 모든 컷에 반복하지 않아. CTA 구간은 진입이 끝나면 제품명·행동·조건을 정지시켜.
  1. 작은 한글 본문은 글자별 분해보다 단어·행 단위로 공개해. 글자별 동작이 필요하면 한글 자모가 분리되지 않게 완성 글자 단위를 사용해. [L3]

3. 구조 템플릿

아래 구간은 최종 타임라인 기준이야. 진입·전환·정지 시간을 해당 구간 안에 포함해. 겹치는 전환은 인접 비트의 경계 안에서 처리하며 표 길이 뒤에 추가하지 않아. 30fps 작업 시작값이면 0.1초는 3프레임. 다른 프레임률에서는 실제 프레임 경계로 반올림해. 모든 길이와 비트 배치는 설계 제안이야.

용도: 이미지를 각인하거나 긴 광고의 핵심 약속을 한 번 더 알릴 때. 공식 범퍼 규격과 초반 브랜드 방향 참고. [S4][S1]

5. 에이전트 프롬프트 예시 3개

예시 1. 15초 SaaS 소개·홍보

routes/소개홍보.md의 판단 순서와 B 템플릿으로 일정 관리 서비스 ‘팀캘’의 15초 9:16 소개 영상을 설계해. 대상은 일정 조율이 잦은 소규모 팀, 약속은 ‘팀 일정을 한 화면에서 확인’, CTA는 ‘무료로 시작하기’, 실제 도착 위치는 게시물에 연결된 가입 페이지야. 제공된 실제 녹화의 일정 선택·공유 화면만 증거로 써. 비용·시간 절감 수치는 만들지 마. 첫 프레임에 문제와 제품 단서를 넣고 4.5~9.5초에는 핵심 조작 하나만 보여 줘. 대비 컷 → 제품 리빌 → 클릭·결과 → 확대 콜아웃 → CTA 정지 조합을 써. 장면별 시작·종료 초, 카피, 주효과, 이징, 이동량, 완성 상태 홀드, 자막, 음향, 저모션 대안을 표로 제시한 뒤 제작해. 무음에서도 이해되게 하고 실제 게재 UI에서 안전 영역을 확인해. 대기를 줄이면 생략을 표시하고 12~15초 CTA는 진입 후 정지해.

예시 2. 12초 제품 출시 티저

이 루트의 D 템플릿으로 무선 조명 ‘루미’의 12초 출시 티저를 설계하고 제작해. 대상은 작은 방을 꾸미는 사용자, 핵심 차별점은 제공된 영상에서 확인되는 조명 색 전환, 출시일은 2026년 11월 10일, CTA는 ‘출시 알림 신청’이야. 제품 사진·실제 사용 클립·승인 로고를 사용해. 0~1.5초에 조명의 구별되는 세부와 브랜드 단서, 4~7초에 전체 제품 리빌, 8.5~12초에 날짜와 CTA를 배치해. 부분 인서트 → 작은 푸시인 → 마스크 리빌 1회 → 로고 선 드로우 → 날짜·CTA 정지 조합을 써. 섬광·스트로브·과도한 카메라 회전을 넣지 마. 날짜는 처음부터 완성된 값으로 보여 줘. 장면표에 리빌 전후 정지 화면, 효과 시간·배율·이징, 사운드 큐, 자막, 저모션 대안을 포함해. 무음으로 제품명·일자·신청 행동이 전달되는지 검수해.

예시 3. 6초 서비스 범퍼와 훅 비교

이 루트의 A 템플릿으로 가상 파일 정리 서비스 ‘파일핏’의 6초 YouTube 범퍼를 제작해. 30fps 기준 총 180프레임으로 맞춰. 약속은 ‘흩어진 문서를 한곳에’, CTA는 ‘자세히 보기’ 하나야. 승인된 실제 폴더 정리 화면만 사용하고 자동화 범위·속도·절감률을 추가로 주장하지 마. 결과 인서트 → 제품 리빌 → 짧은 로고 스팅 → CTA 정지 조합을 써. 4.4~6.0초에는 CTA 진입 0.2초와 정지 1.4초를 배치하고, 문구가 읽히지 않으면 스팅을 줄여. 첫 1초만 ‘흩어진 폴더’와 ‘정리된 결과’로 다르게 만든 두 버전을 제시하고 나머지 장면·길이·CTA·음향은 동일하게 유지해. 비교할 지표와 플랫폼의 실제 집계 정의를 기록해. 6초 범퍼의 완주율만으로 구매 효과를 판정하지 말고, 제품·약속·행동 회상도 확인해. 무음·작은 화면·최종 로고 가독성을 검수해.

프롬프트에 등장하는 서비스·제품과 출시일은 지시문 예시용 설정이야. 실제 작업에서는 승인된 제품 정보·소재·일자로 교체해. 입력이 부족하면 주장을 발명하지 말고 확인이 필요한 값을 표시해.

6. 체크리스트와 완성 판정

완성은 ‘화려한가’가 아니라 대상 시청자가 제품, 이익, 증거, 다음 행동을 재생 환경에서 이해할 수 있는가로 판단해. 아래 표에서 필수 항목을 통과하고, 조건부 항목은 해당 여부와 확인 결과를 남겨.

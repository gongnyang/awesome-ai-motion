영상편집: 설명·강의 영상의 모션 활용 루트

조사·웹 확인일: 2026-09-30. 대상: 설명·강의 영상의 컷 리듬, 전환, 자막, 화면 입력 시연, 도해 애니메이션, 나레이션 싱크.

핵심 루트: 학습 목표 → 시청 조건 → 의미 비트 → 확정 음성 → 읽기 예산 → 화면 상태 → 효과 조합 → 검수. 움직임은 설명 대상·순서·변화·인과를 읽게 하는 데 배정해. 이해가 끝나기 전에 다음 화면으로 넘기지 마.

근거 표기: [S]는 끝의 웹 출처, [L]은 로컬 사전이야. 연구 원리·공식 규격과 제작 제안을 구분해. 별도 표시 없는 시간·거리·글자 크기·동기 오차는 이 루트의 제작 시작값이야. 학습 효과가 검증된 최적값이나 분석한 영상의 실측값으로 읽지 마. 블로그의 일반 팁·검색 요약은 근거로 채택하지 않았어.

5. 에이전트 프롬프트 예시 3개

예시 1: 90초 개념 설명

이 루트의 A 템플릿으로 ‘언어 모델은 다음 토큰을 예측한다’를 설명하는 16:9·1080p·90초 영상 설계안을 만들어. 대상은 AI 용어가 낯선 직장인이야. 목표는 입력·예측·추가의 관계와 ‘예측이 사실 확인을 보장하지 않는다’는 한계를 자기 말로 설명하는 거야. 새 용어는 토큰·컨텍스트만 먼저 소개해. 고정 도해에 점진적 공개·연결선·현재 단계 강조를 조합하고, 마지막에 조건을 바꾼 예측 질문을 넣어. 절대 초 타임라인·발화·의미 큐의 기준점·자막·효과 시간·이징·완성 홀드를 표로 출력해. 음성이 아직 없으면 시간표를 초안으로 표시해. 후보 확률·모델 결과를 임의 실측값으로 만들지 말고 설명용 예시를 표시해. 제작 제안과 출처 근거, 읽기 예산, 모션을 줄인 대안, 실제 렌더에서 확인할 항목을 함께 적어.

예시 2: 180초 화면 입력 시연

제공한 실제 화면 녹화·음성·원문 자료로 ‘회의록에서 결정 사항을 추출하고 원문으로 검증하기’ 180초 영상을 B 템플릿에 맞춰 편집 설계해. 전체 화면→입력창 확대→핵심 조건 입력→실행→결과→원문 비교 순서를 유지해. 원본의 클릭·응답 타임코드를 먼저 확인하고, 긴 대기만 점프컷과 생략 표시로 압축해. 새로 그린 커서는 실제 행동과 구분해. 자막은 발화·중요 소리·화자를 반영하고 부정어·수치·조건을 수동 검토해. 원본 소스 구간과 출력 타임코드를 대응시키고 효과·이징·읽기 홀드·가림 여부를 표로 써. 잘못된 출력은 검증 장면에 남겨. 자료가 없으면 성공 결과를 꾸미지 말고 필요한 입력과 미확인 상태를 적어. 폰 독해·무음·음성만 청취·전환 경계 검사를 완성 판정표에 포함해.

예시 3: 300초 미니 강의 편집

이 루트의 C 템플릿으로 ‘좋은 프롬프트와 결과 검증’ 300초 미니 강의 편집안을 만들어. 목표는 학습자가 역할·자료·출력 형식을 정하고 결과를 원문과 대조하는 거야. 초보 대상, LMS·데스크톱과 폰 재생, 발화 자막과 주요 시각 결과의 음성 설명이 필요해. 확정 대본·음성·실제 UI 자료를 기준으로 개념→시연→반례→새 사례 적용 순서를 설계해. 장면마다 주효과 하나와 보조 강조 하나부터 고르고, 고정 컷 빈도를 강제하지 마. 의미 큐·J/L 컷의 선행/잔류·챕터·자막 읽기 예산·완성 도해 홀드·질문 대기를 포함한 초 단위 큐시트를 출력해. 300초에 독해가 안 되면 축소할 범위 또는 필요한 연장 시간을 제안해. 연구·공식 규격·제작 제안을 구분하고 렌더 확인 전에는 납품 완료로 선언하지 마. 최종 검수에는 영상 뒤 개념 질문과 같은 과제 수행을 포함해.
